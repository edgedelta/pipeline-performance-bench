Microbenchmark: processors::aggregate_metric::tests::benchmark_metric_context
Build: cargo test --release --locked --target x86_64-unknown-linux-gnu --lib --no-run (Zig linker/C toolchain for cross-compilation)
Reproduce natively on Linux: cargo test --release --locked --lib benchmark_metric_context -- --ignored --nocapture --test-threads=1
Run: <library-test-executable> processors::aggregate_metric::tests::benchmark_metric_context --ignored --nocapture --test-threads=1

Same executable compares forced full metric context against field-only context.
Eight alternating-order rounds, 1,000 batches of 512 points per mode per round.
Delta sums with host and route attributes, 64 recurring resource groups and eight
10-second event-time windows. Input construction and output serialization are
outside the measured loop; resource Arc replacement is included in both modes.
Each pair checks identical sorted serialized aggregate output. This isolates
aggregation observe cost; it excludes decoding, transport, scheduling and flush.

The unit-test executable uses the system allocator, while the agent binary uses
mimalloc. Local timings are a screening result, not a throughput prediction.
The separately scored agent trials use the production release binary and mimalloc.
